Introduction

JavaScript is one of the most popular programming languages used to create interactive and dynamic websites.

Learning JavaScript requires a strong understanding of basic concepts such as variables, data types, operators, loops, functions, scope, hoisting, parameters and arguments.

This article covers important JavaScript topics and logical problems using the for loop.

Important JavaScript Topics

1. Variables

A variable is a container used to store data in JavaScript. Variables can store numbers, strings, boolean values and other types of data. 


let name = "Janani";
let age = 22;
const country = "India";

console.log(name);
console.log(age);
console.log(country);

2. var

var is an older keyword used to declare variables in JavaScript. It is function scoped and allows both reassignment and redeclaration. 


var age = 20;

age = 21;

var age = 22;

console.log(age);

Output: 22

  • Function scoped
  • Can be reassigned
  • Can be redeclared
  • Hoisted with undefined

3. let

let was introduced in ES6. It is block scoped and can be reassigned but cannot be redeclared in the same scope. 


let age = 20;

age = 21;

console.log(age);

Output: 21

  • Block scoped
  • Can be reassigned
  • Cannot be redeclared in the same scope
  • Has Temporal Dead Zone

4. const

const is used when a variable should not be reassigned after initialization. 


const pi = 3.14;

console.log(pi);

Output: 3.14

  • Block scoped
  • Cannot be reassigned
  • Cannot be redeclared
  • Must be initialized during declaration
  • Has Temporal Dead Zone

Primitive Data Types

let name = "Janani";

    name: "Janani",

6. Operators

Operators are symbols used to perform operations on values.

Arithmetic Operators

==   ===   !=   !==   >   <   >=   <=

7. Loop Statements

Loops are used to execute a block of code repeatedly.

  • for loop
  • while loop
  • do...while loop
  • for...of loop
  • for...in loop

for Loop Example


for (let i = 1; i <= 5; i++) {
    console.log(i);
}

8. Functions

A function is a reusable block of code designed to perform a particular task.

Function Declaration


function add(a, b) {
    return a + b;
}

console.log(add(10, 20));

Arrow Function


const add = (a, b) => {
    return a + b;
};

Short Arrow Function


const add = (a, b) => a + b;

9. Scope and Hoisting

Scope

Scope determines where a variable can be accessed in a JavaScript program.

  • Global Scope
  • Function Scope
  • Block Scope

let name = "Janani";

function display() {
    let age = 22;

    console.log(name);
    console.log(age);
}

display();

Hoisting

Hoisting is JavaScript's behavior of processing declarations before executing the code. 


console.log(age);

var age = 22;

Output: undefined

10. Parameters and Arguments

Parameters are variables defined in a function declaration. Arguments are the actual values passed to the function. 


function multiply(a, b) {
    return a * b;
}

console.log(multiply(5, 4));

a and b are parameters.

5 and 4 are arguments.

Output: 20

10 For Loop Logical Problems

Practice these problems to improve your JavaScript logical thinking.

Problem 1: Print Numbers from 1 to 20

Write a program using a for loop to print numbers from 1 to 20.


for (let i = 1; i <= 20; i++) {
    console.log(i);
}

Problem 2: Print Even Numbers

Print all even numbers from 1 to 50.


for (let i = 1; i <= 50; i++) {
    if (i % 2 === 0) {
        console.log(i);
    }
}

Problem 3: Print Odd Numbers

Print all odd numbers from 1 to 50.


for (let i = 1; i <= 50; i++) {
    if (i % 2 !== 0) {
        console.log(i);
    }
}

Problem 4: Find Sum from 1 to 100

Calculate the sum of all numbers from 1 to 100.


let sum = 0;

for (let i = 1; i <= 100; i++) {
    sum = sum + i;
}

console.log(sum);

Output: 5050

Problem 5: Multiplication Table

Print the multiplication table of 7 from 1 to 10.


let number = 7;

for (let i = 1; i <= 10; i++) {
    console.log(
        number + " x " + i + " = " + (number * i)
    );
}

Problem 6: Count Even Numbers

Count how many even numbers exist between 1 and 100.


let count = 0;

for (let i = 1; i <= 100; i++) {
    if (i % 2 === 0) {
        count++;
    }
}

console.log("Even Count:", count);

Output: Even Count: 50

Problem 7: Find Largest Number

Find the largest number in an array using a for loop.


let numbers = [10, 45, 23, 78, 12];

let largest = numbers[0];

for (let i = 1; i < numbers.length; i++) {
    if (numbers[i] > largest) {
        largest = numbers[i];
    }
}

console.log("Largest:", largest);

Output: Largest: 78

Problem 8: Reverse a Number

Reverse the number 12345 using a for loop.


let number = 12345;
let reverse = 0;

for (; number > 0; number = Math.floor(number / 10)) {
    let digit = number % 10;
    reverse = reverse * 10 + digit;
}

console.log(reverse);

Output: 54321

Problem 9: Check Prime Number

Check whether a number is a prime number using a for loop.


let number = 29;
let isPrime = true;

if (number < 2) {
    isPrime = false;
}

for (let i = 2; i < number; i++) {
    if (number % i === 0) {
        isPrime = false;
        break;
    }
}

if (isPrime) {
    console.log(number + " is a Prime Number");
} else {
    console.log(number + " is Not a Prime Number");
}

Output: 29 is a Prime Number

Problem 10: Armstrong Number

Check whether a number is an Armstrong number.

For example: 153 = 1³ + 5³ + 3³ = 153 


let number = 153;

let original = number;

let digits = String(number).length;

let sum = 0;

for (; number > 0; number = Math.floor(number / 10)) {
    let digit = number % 10;
    sum = sum + digit ** digits;
}

if (sum === original) {
    console.log(original + " is an Armstrong Number");
} else {
    console.log(original + " is Not an Armstrong Number");
}

Output: 153 is an Armstrong Number
