1.What is React

React is a JavaScript library used to build user interfaces (UI), especially for web applications.React is an open-source JavaScript library used to build interactive and reusable user interfaces, especially for web applications. React was created at Facebook and was open-sourced in 2013.

2.Is React a library or framework

React is a JavaScript library, not a framework.

Library: We use it for a specific purpose, mainly building UI.

Framework: Usually provides a more complete structure for building an application.



3.What is a component

React applications are built using components.Each component can contain its own UI and logic and can be reused when needed. This makes larger applications easier to develop, test, understand, and maintain.



4.Why are components important

The component can be reused.

Easy to maintain.

Easy to update.



5.What is JSX

JSX (JavaScript XML) is a syntax that allows us to write HTML-like code inside JavaScript.

JSX makes React code easier to read and write.



6.What is Virtual DOM

The Virtual DOM is a lightweight representation of the Real DOM maintained by React in memory.

This helps React update the UI efficiently.



7\.What is the Real DOM

The Real DOM (Document Object Model) is the actual structure of the webpage in the browser.

The browser creates DOM elements for these HTML elements.

If the DOM changes frequently, updating it directly can be expensive, especially for large applications.



8\.What is reconciliation

Reconciliation is the process React uses to determine what changed in the UI and what needs to be updated in the Real DOM.
